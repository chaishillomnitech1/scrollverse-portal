# ScrollVerse Trinity Portal Showcase

This repository contains the ScrollVerse Trinity Portal showcase.

## Deployment to Vercel

This project can be easily deployed to Vercel. Follow these steps:

1. **Sign up or Log in to Vercel:** If you don't have a Vercel account, sign up at [vercel.com](https://vercel.com/).
2. **Import Your Project:** Go to your Vercel dashboard and click "New Project". Select "Import Git Repository" and choose this repository (chaishillomnitech1/scrollverse-portal).
3. **Configure Project:** Vercel should automatically detect that this is a Node.js project. Ensure the "Build and Output Settings" are correctly configured (typically, Vercel handles this automatically for static sites).
4. **Deploy:** Click "Deploy". Vercel will build and deploy your project.

Once deployed, your ScrollVerse Trinity Portal showcase will be live!
